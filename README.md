# Flight Price Prediction

A machine learning project that predicts flight ticket prices using historical flight data and a Linear Regression model.

## Overview
This project explores the relationship between flight-related features (such as route, timing, and other trip details) and ticket pricing, using supervised machine learning to build a predictive model.

## Data
The dataset consists of historical flight pricing records, including route and pricing information used to train and evaluate the model.

## Approach
- Data cleaning and preprocessing
- Feature preparation
- Model training using Linear Regression
- Price prediction and evaluation

## Tools & Libraries
- Python
- pandas
- scikit-learn
- Jupyter Notebook

## Files
- `ML.ipynb` — main notebook containing data processing and model training
- `flights_data.csv` / `data.csv` — flight data used for training
- `linear_regression_model` — trained model file

## Status
This is a personal learning project developed to apply core machine learning concepts in a real-world context.
